# V2-6 — НДС в смете и её PDF

Ветка `ver-2`. **Миграция 0069** (по два новых столбца в `executor_profiles` и `estimates`, оба допускают NULL; обратимая; существующие строки не меняются). Решения владельца 2026-10-24: цены в прайсе — **нетто**, НДС добавляется сверху; объём — **только смета и её PDF** (старые сметы и выданные документы не меняются; договор сохраняет свой `vat_rate_percent`; платежи и «предложение согласованной суммы» не затрагиваются).

## Модель

* `vat_mode` (`EXEMPT` = «zw.», `RATE`, NULL = «НДС не задан») и `vat_rate_percent` (8 или 23, только при `RATE`) — в профиле исполнителя и в смете; проверочное ограничение в базе (`ck_executor_profiles_vat`, `ck_estimates_vat`) и то же правило в коде (`app/domain/rules/vat.py`).
* Все существующие сметы и профили получают NULL/NULL: вид и суммы не меняются (никаких строк НДС).

## Правила (`vat.py`, детерминированно)

* Итог строк сметы — это **нетто**. `RATE`: НДС = нетто × ставка / 100, округление до копейки «половина вверх» **от итога** (не по строкам); брутто = нетто + НДС. `EXEMPT` и «не задан»: НДС и брутто не считаются (суммы без изменений).
* Новая смета (первая версия, новая версия после выпуска) берёт НДС из профиля на момент создания; значение копируется в смету и дальше от профиля не зависит.
* Профиль: `PUT /api/executor-profile` — ключи НДС необязательны; **не присланные не затирают** сохранённое (старый экран не сбросит ставку), присланные (в том числе `null`) заменяют. Неверное сочетание → 422 `EXECUTOR_PROFILE_INVALID`, `fields: {"vat": "VAT_INVALID"}`.
* Смета: `PUT /api/projects/{p}/estimates/{e}/vat` (`vat_mode`, `vat_rate_percent`; null/null = не задан) — только для **DRAFT** (иначе 409), неверное — 422, чужой владелец — 404. Ответ — сводка сметы с `vat_amount` и `gross_total`.
* Остальные API (`EstimateRead`, `EstimateSummaryRead`) отдают `vat_mode`, `vat_rate_percent`, `vat_amount`, `gross_total`.

## PDF и экран

* PDF сметы: при `RATE` — «Razem netto / VAT {ставка}% / Razem brutto» и примечание; при `EXEMPT` — «zw.» с примечанием; без НДС — как раньше. Выданные ранее PDF не пересобираются.
* Экран «Profil wykonawcy»: список «Stawka VAT w kosztorysach» (не задано / zw. / 8 % / 23 %).
* Экран сметы: в шапке нетто, «VAT N %», брутто (или «zw.»), для черновика — список «VAT» (смена без перезагрузки позиций). Список версий показывает брутто, если задана ставка.
