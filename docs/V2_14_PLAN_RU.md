# V2-14 — ссылка для мастера (электрик и сантехник по отдельности)

Запрос владельца (2026-11-03, после V2-13): когда вы сами не электрик и не сантехник (руководитель работ, замерщик), мастеру нужна **своя ссылка — отдельно электрику, отдельно сантехнику**, «на подобие ссылки для заказчика»: страница с **чеклистом точек и трасс**, где мастер уточняет, какие должны быть точки, кабели, трубы, и может **добавить свои варианты**.

## 1. Решения владельца (2026-11-03)

| Вопрос | Решение |
| --- | --- |
| Что заполняет мастер | **Типовые позиции по помещениям**: электрик — розетки, выключатели, точки света, цепи (автоматы), трасса кабеля, м; сантехник — точки воды, точки канализации, выходы коллектора, трасса трубы, м. Количество на помещение + короткая пометка |
| Что видит мастер (без цен) | **Помещения с размерами** (название, площадь пола, высота, периметр); **фото помещения и карту трасс** (метки «Mapa instalacji» только его профессии); **ваш комментарий мастеру** (текст при создании ссылки). Без клиента, цен, заметок, других объектов |
| Свои варианты и дальше | **Свои позиции** (название, количество, шт. или м, пометка) + у вас **кнопка «Перенести»**: типовые идут в «Punkty i trasy» и в материалы помещения, свои остаются текстом с пометкой |
| Ссылки и уведомления | **Две ссылки на объект** (электрику и сантехнику), как ссылка клиента: 30 дней, «Продлить» / «Отозвать», язык PL/RU/UK/EN; когда мастер нажимает «Wyślij odpowiedź» — вам сообщение в Telegram |

## 2. Этапы (каждый — со своей выкладкой и приёмкой)

* **V2-14 (этот шаг):** ссылки, страница мастера, чеклист типовых позиций и свои позиции по помещениям, имя мастера, «Wyślij odpowiedź» с сообщением вам в Telegram, ваш комментарий мастеру, экран у вас: статус ссылок, ответы по помещениям, журнал отправок. Миграция **0085**.
* **V2-14a:** кнопка «Перенести» — типовые ответы в «Punkty i trasy» и в материалы помещения (только по вашей кнопке, повтор не дублирует).
* **V2-14b:** фото помещений и карта трасс его профессии на странице мастера (подписанные ссылки на фото, только фото этого объекта и только метки его профессии).

## 3. Что я решил сам (можно отменить)

* **Каркас — как у ссылки клиента (V2-8):** `https://<домен>/m#<токен>`, секрет во фрагменте, в заголовке `X-Trade-Link`; 32 случайных байта, в базе только SHA-256; одна действующая ссылка **на объект и профессию**; «Новая ссылка» отзывает прежнюю; неизвестный токен — одинаковый 404, просроченная / отозванная — 410; лимиты запросов по адресу (в памяти); заголовки `no-store`, `noindex`, `no-referrer`.
* **Мастер правит ответы, пока ссылка жива** (автосохранение по помещению), а **«Wyślij odpowiedź»** — отдельное событие: имя мастера (обязательно), запись в журнал отправок, сообщение вам. Можно отправить снова после правок; журнал только добавляется.
* **Что видит мастер об объекте:** название объекта и помещения; адрес и имя клиента **не показываются** (адрес вы можете написать в комментарии).
* **Типовые позиции — справочник в правилах** (`domain/rules/trade_checklist.py`), а не в React; названия берутся из словарей четырёх языков.
* **Зашифровано (ключ владельца):** комментарий владельца, имя мастера, свои позиции мастера (название, пометка), пометки к типовым позициям.

## 4. Данные (миграция 0085, 3 НОВЫЕ таблицы; существующие не меняются)

* `trade_links`: `id`, `owner_id`, `project_id`, `trade` (ELECTRIC / PLUMBING), `token_hash` (уникален), `language`, `owner_note`*, `created_at`, `expires_at`, `revoked_at`, `last_viewed_at`, `view_count`. Частичный уникальный индекс: одна неотозванная на (`project_id`, `trade`).
* `trade_answers`: `id`, `owner_id`, `project_id`, `link_id`, `room_id` (CASCADE), `position_key` (типовая) **или** `custom_name`* (своя), `quantity` numeric(8,2), `unit` (PCS / LM), `note`*, `created_at`, `updated_at`. Уникально: одна строка на (`link_id`, `room_id`, `position_key`); своих позиций — не более 30 на помещение.
* `trade_submissions` (журнал): `id`, `owner_id`, `project_id`, `link_id`, `master_name`*, `answers_hash`, `answers_count`, `ip_hash`, `agent_hash`, `created_at`. Только добавляется.
* Всё с `ON DELETE CASCADE` от объекта и владельца. Зашифрованных колонок станет 78 (было 74).

## 5. API

Публичное (3 новые операции; токен в заголовке `X-Trade-Link`):

* `GET /api/public/trade` — страница: исполнитель (название, телефон), объект (название), профессия, комментарий владельца, помещения с размерами и ответами мастера, справочник типовых позиций, срок ссылки.
* `PUT /api/public/trade/rooms/{room_id}` — ответы по одному помещению (типовые: ключ → количество / пометка; свои: список), заменяют прежние ответы этого помещения.
* `POST /api/public/trade/submit` — `{master_name}`: запись в журнал, сообщение владельцу.

Для владельца (с входом): `GET /api/projects/{id}/trade-links` (обе ссылки и сколько ответов), `POST /api/projects/{id}/trade-links/{trade}` (создать; `{language, note}`), `PATCH` (комментарий), `POST …/extend`, `DELETE …` (отозвать), `GET …/{trade}/answers` (ответы по помещениям и журнал отправок).

## 6. Экран

* **Владелец** (в объекте, плитка «Ссылка для мастера»; рядом с «Ссылка для клиента»): две карточки — «Elektryk» и «Hydraulik»: создать / новая ссылка, копировать, отправить в Telegram, срок, «Продлить», «Отозвать», комментарий мастеру, когда открывали; ниже ответы по помещениям (что вписал мастер, свои позиции) и журнал «Wysłano».
* **Мастер** (`/m`): шапка с исполнителем; комментарий; помещения (раскрывающиеся): размеры, чеклист типовых позиций (поле количества, пометка), «Dodaj własną pozycję»; блок «Wyślij odpowiedź» (имя + кнопка); состояния: загрузка, ссылка неактивна, ошибка, отправлено. Mobile-first 320–480 px, цели ≥ 44 px, без горизонтальной прокрутки, PL/RU/UK/EN; язык мастера в памяти браузера не сохраняется.

## Критерии PASS (этап V2-14)

1. Правила: токен, чистка количества / пометок / имён, справочник типовых позиций (ключи, единицы, профессии).
2. Сервисы и API: создание / продление / отзыв, одна ссылка на (объект, профессия), чужой владелец — 404, ответы заменяют ответы помещения, чужое помещение — отказ, лимиты размеров, отправка пишет журнал и шлёт сообщение; публичные ответы — белый список полей (нет цен, клиента, адреса).
3. Публичных операций без входа стало **шесть** (3 клиента + 3 мастера): аудит API и скрипт выкладки обновлены.
4. Миграция 0085 вверх / вниз / вверх на PG16; откат отказывает, пока есть ответы / журнал.
5. Экран: 4 языка, 320 / 390 / 419, светлая / тёмная, без горизонтальной прокрутки, цели ≥ 44 px; регрессия (4 шарда, vitest, tsc, build); скрипт выкладки с миграцией 0085 + пробный прогон; README пошагово.
