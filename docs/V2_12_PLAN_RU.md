# V2-12 — пакеты «Электрика» и «Сантехника» (материалы), затем карта скрытых коммуникаций и протокол опрессовки

Решения владельца (2026-10-31, после приёмки V2-11): V2-12 делится на **три шага, каждый со своей приёмкой**: **V2-12** — материалы электрика и сантехника; **V2-12a** — карта скрытых коммуникаций на фото; **V2-12b** — протокол опрессовки (форма + PDF). Следующий шаг начинается только после вашего «да». Ниже — **V2-12** (материалы); V2-12a и V2-12b — в конце как намерения (уточним перед стартом).

## V2-12: идея
Те же правила, что у V2-11: **чистая функция** от исходных данных и **ваших норм** (без ИИ, цены в формулах не участвуют, результат не хранится). Два новых пакета в том же экране «Materiały» помещения, той же ведомости объекта, тех же строк в смету и тех же норм — без нового экрана.

## 1. Расчёты у помещения
* **Электрика** («Elektryka»): розеток, выключателей, светильников (шт), цепей / автоматов (шт) и необязательно **длина кабеля по трассам, м** (если не указана — считается по числу точек и нормам «метров кабеля на точку»). Кнопка рядом подставляет **трассы электрики этого помещения** (сумма ваших строк «Punkty i trasy» в мп из позиций категории «Электрика»).
* **Сантехника** («Hydraulika»): точек воды (шт), точек канализации (шт), выходов коллектора (шт, 0 — без коллектора) и необязательно **длина трубы водоснабжения, м** (иначе — по точкам и норме). Кнопка рядом подставляет **трассы сантехники помещения** (мп позиций категории «Сантехника»).

## 2. Формулы (все числа — из справочника норм)
* **Электрика.** Длина кабеля L = длина по трассам, если задана, иначе розетки × 6 + выключатели × 4 + светильники × 5 (м). Кабель = L × (1 + запас 10 %), кругов по 100 м. Гофра = L × доля 100 % × (1 + запас), бухт по 50 м. Подрозетники = розетки + выключатели; розетки; выключатели; автоматы = цепи; распаечные коробки = цепи × 1; клеммы = (розетки + выключатели + светильники) × 3, упаковок по 50.
* **Сантехника.** Труба воды P = длина по трассам, если задана, иначе точки воды × 4 м. Труба = P × (1 + запас 10 %), бухт по 100 м. Фитинги = точки воды × 4 шт; краны = точки воды × 1; коллектор = выходы (шт); крепёж = P × 2 шт/м, упаковок по 100. Канализационная труба = точки канализации × 2 м, штанг по 2 м; фитинги канализации = точки канализации × 3.
* Материалы с количеством 0 в расчёт не попадают. Округление вверх до целой упаковки; по объекту упаковки округляются один раз по сумме расчётов (как в V2-11).

## 3. Справочник норм
Новые строки в том же справочнике «Normy zużycia» (группы «Elektryka» и «Hydraulika»): числа (метров на точку, запасы, размеры бухт и упаковок, штук на точку) и материалы (название, привязка к позиции прайса в шт). Стартовые цифры — **ориентир**: проверьте по тем материалам, которые берёте. Нормы создаются при первом открытии автоматически (у тех, кто уже открывал нормы, добавляются недостающие строки).

## 4. Данные (миграция 0079, обратимая)
Данных новых таблиц нет: только расширяется проверка значения «пакет» (`TILE`, `DRYWALL` → ещё `ELECTRIC`, `PLUMBING`) в `material_norms` и `material_calcs`. Откат **отказывается**, пока есть расчёты электрики / сантехники или изменённые вами нормы этих пакетов; нетронутые стартовые строки норм удаляются (пересоздадутся при следующем открытии).

## 5. API
Прежние маршруты V2-11 принимают новые пакеты; новый маршрут `GET /api/projects/{id}/rooms/{room}/route-totals` (суммы трасс помещения в мп: электрика, сантехника) для кнопок подстановки.

## Критерии PASS
1. Формулы — чистые тесты с вручную посчитанными числами (по точкам и по длине трасс, нули, округление упаковок, сумма по объекту).
2. API: создание, правка, ошибки, чужой владелец — 404; нормы новых пакетов создаются и правятся; суммы трасс по категории; строки в смету из новых материалов.
3. Миграция 0079 вверх / вниз / вверх на PG16; откат отказывает при данных.
4. Экран: 4 языка, 320 / 390 / 419, светлая / тёмная, нет горизонтальной прокрутки, цели ≥ 44 px, 🎤 у чисел; регрессия (4 шарда, vitest, tsc, build); скрипт выкладки с миграцией + пробный прогон; README пошагово.

## V2-12a (после «да»)
