# V2-4 — быстрая смета

Ветка `ver-2`. Миграции нет: признак «быстрая» не нужен (смета и объект — обычные; быстрый только путь создания). Решения владельца 2026-10-24: клиента выбрать или создать на том же экране; галочки — пять стартовых работ + потолок; проёмы не учитываются (потом правятся обычным экраном).

## Что делает

Один экран «Szybka wycena» (кнопка «⚡» на списке объектов): клиент (выбор из списка или имя и телефон) → адрес и город → помещения по трём размерам (длина × ширина × высота, быстрые названия) → галочки работ → «Sufit też» (потолок) → подложка и класс (по умолчанию гипсовая штукатурка, S2) → «Policz».

Бэкенд одним запросом создаёт обычные сущности теми же службами: клиент (если новый), объект «Szybka wycena · адрес», помещения (пол, потолок, 4 стены), план работ на каждой стене (и на потолке, если включён) с выбранными работами, и обычную черновую смету (DRAFT). Приложение открывает экран сметы объекта; «Finalizuj» и PDF — существующими кнопками.

## Правила

* Работы и их порядок лежат на бэкенде (`quick_estimate_data.py`): стены — защита (выкл.), грунт, гладь 2 слоя, шлифовка, покраска 2 слоя (вкл.); потолок — те же, но покраска потолка (`CENNIK_PAINT_CEIL-01`). Цен в коде нет: цены только из прайса владельца; позиции без цены остаются «Do ustalenia» и экран предлагает окно цен.
* Проёмы не вычитаются; в ответе и на экране прямо сказано «bez odjęcia otworów».
* Всё проверяется ДО создания (размеры, список работ, пара «подложка — класс», клиент); одна ошибка — ничего не создано. Дальше службы коммитят по шагам (как везде); при сбое в середине остаётся обычный объект, который удаляется из архива.
* Ключ шифрования ставит запрос; тесты — с включённым шифрованием и строгим чтением.
* Мобильный экран (320/390/412, ≥44 px, PL/RU, светлая/тёмная), без горизонтальной прокрутки; тексты только в `pl.json` / `ru.json`.

## Тесты / PASS

Фронтенд: форма, помещения, галочки, расчёт, переход к смете, ошибки. Реальное приложение: полный путь на всех размерах. Выкладка без миграции: `docs/V2_4_DEPLOY_RU.sh`.
