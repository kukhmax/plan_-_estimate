# V2-12a — карта скрытых коммуникаций на фото

Решения владельца (2026-10-31, после приёмки V2-12): карта живёт **на любом фото** — у метки появляется «Тип коммуникации»; типы: **кабель, холодная вода, горячая вода, канализация, отопление, газ**; у метки указываются **глубина в стене / штробе, расстояние от пола, расстояние от угла / косяка (см)** и короткая заметка (поле «подпись», как раньше, до 40 знаков); карта видна **в просмотре фото (легенда и цвета)**, **в PDF «Raport fotograficzny»**, **в PDF «Obmiar obiektu» с галочкой «Добавить фото»** и **отдельным листом «Mapa instalacji ukrytych» (PDF)**.

## Идея
Метка фото (14G) уже умеет место на снимке, подпись и контур. Добавляются **тип коммуникации** и **три расстояния** — необязательные поля метки; контур, нарисованный вокруг метки, становится линией трассы в цвете типа. Ничего не считается: расстояния — то, что ввёл мастер.

## 1. Данные (миграция 0080, обратимая)
Четыре новых nullable-колонки `photo_annotations`: `utility` (строка с CHECK: `CABLE`, `WATER_COLD`, `WATER_HOT`, `SEWER`, `HEATING`, `GAS`), `depth_cm`, `from_floor_cm`, `from_corner_cm` (`numeric(5,1)`, CHECK 0…1000). Существующие метки не меняются. Откат **отказывает**, пока есть метка с типом или расстоянием.

## 2. Экран
* Окно метки (нижняя шторка): ряд кружков-вариантов «Обычная метка / Кабель / Холодная вода / Горячая вода / Канализация / Отопление / Газ» (по одному на нажатие, цель ≥ 44 px, на 320 px два столбца); при выбранном типе — три числовых поля (запятая, одна цифра после запятой, 0…1000, голос не нужен); «Сохранить» отправляет только изменённое.
* Цвета: кабель — оранжевый, холодная вода — синий, горячая — красный, канализация — серый, отопление — фиолетовый, газ — коричневый; обычная метка — красная, как раньше. Контур метки рисуется её цветом.
* Под снимком (если хоть у одной метки есть тип) — **легенда**: номер в цвете типа и текст «тип · подпись · от пола · от угла · глубина».

## 3. PDF
Те же цвета и тексты (польские) в **Raport fotograficzny** и **Obmiar obiektu** с фото: цветные метки и контуры, под фото «Oznaczenia: 1 – przewód elektryczny · do gniazda · od podłogi 30 cm · głębokość 3 cm; …». Палитра в коде PDF и в экране — одна (тест сверяет).

## 4. Отдельный лист «Mapa instalacji ukrytych» (миграция 0081, обратимая)
Новый вид документа `INSTALLATION_MAP`, префикс номера `MAP`: все фото объекта, у которых хоть одна метка имеет тип (отмечены они для отчёта или нет), сгруппированы по помещениям (фото объекта — первой группой «Obiekt»), с ключом «Rodzaje instalacji» (какие типы есть и их цвета) и пометкой, что расстояния ориентировочные. Две формы: рабочая (водяной знак, без номера и записи в журнале, не отказывает при отсутствии фото) и пронумерованная (отказ с кодом `INSTALLATION_MAP_EMPTY`, пока нет ни одного такого фото, `INSTALLATION_MAP_PHOTO_LIMIT_EXCEEDED` — больше фото, чем держит один документ, `EXECUTOR_PROFILE_REQUIRED`). Строка «Mapa instalacji» — в меню «PDF-dokumenty». Миграция 0081 расширяет проверку вида в журнале; откат отказывает, пока в журнале есть такая строка.

## Критерии PASS
1. Правила метки: тип из списка, расстояния 0…1000 с одной цифрой; «не прислано — остаётся», `null` — очищает; чужой владелец — 404; БД отказывает неизвестному типу и расстоянию вне диапазона.
2. PDF: цвет по типу у метки и контура, легенда на польском, обычная метка красная; палитра экрана = палитре PDF.
3. «Mapa instalacji»: какие фото попадают, группы, ключ, обе формы, отказы с кодами, настоящие маршруты и настоящий PDF.
4. Миграции 0080 и 0081 вверх / вниз / вверх на PG16; откат отказывает при данных.
5. Экран: 4 языка, 320 / 390 / 419, светлая / тёмная, нет горизонтальной прокрутки, цели ≥ 44 px; регрессия (4 шарда, vitest, tsc, build); скрипт выкладки с двумя миграциями + пробный прогон; README пошагово.
