# V2-7 — украинский и английский языки

Ветка `ver-2`. **Миграция 0070** (меняется только проверка `ck_calendar_settings_language`; ни одна строка и ни один столбец не меняются; обратимая). Решения владельца 2026-10-24: кроме украинского добавляется **английский**; объём — интерфейс + сообщения календаря (база знаний остаётся на PL/RU, PDF клиенту остаются польскими); переключатель — **выпадающий список**; первый язык нового пользователя — **по языку Telegram**.

## Что входит

* **Четыре языка экрана:** PL (по умолчанию), RU, UK, EN. Словари `frontend/src/locales/{pl,ru,uk,en}.json` — одинаковый набор ключей (3141 текст), одинаковые подстановки `{…}`; паритет проверяет тест `locales.parity.test.ts` (ключи, подстановки, пустые тексты, алфавит, формы множественного числа).
* **Переключатель:** в шапке одна кнопка «PL ▾» (минимум 44 px) → список из четырёх строк с названием языка на нём самом (Polski, Русский, Українська, English); закрывается выбором, тапом снаружи и Escape.
* **Первый язык:** сохранённый вручную выбор главнее всего; если его нет — язык Telegram (`uk`→UK, `en`→EN, `ru`→RU, остальное→PL).
* **Форматы:** теги дат/чисел/множественного числа — через одну таблицу (`utils/locale.ts`: pl-PL, ru-RU, uk-UA, en-GB).
* **Сообщения календаря (бот):** `texts.json` на четырёх языках; язык — выбор владельца в «Ustawienia kalendarza» (теперь «как в Telegram» / PL / RU / UK / EN) или, если не выбран, язык его Telegram (раньше: русский или польский).
* **Миграция 0070:** проверка языка `NULL | pl | ru | uk | en`; откат переводит `uk`/`en` в NULL («как в Telegram») и возвращает прежнюю проверку.

## Что остаётся прежним

* Все PDF клиенту — польские (юридическое правило проекта). База знаний (правовые тексты) — PL/RU: при UK/EN показывается польский оригинал (перевод закона без юриста не делается).
* Названия работ прайса-«зерна», шаблоны процессов, чек-листы и тексты рисков — переведены в словаре (они там и хранятся); пользовательские названия остаются как ввёл владелец.
* Переводы подготовлены без носителя языка и без юриста: ранний просмотр владельцем — часть приёмки; правки — обычными коммитами в `uk.json`/`en.json`.
