# V2-2 — демо-данные (команда `seed-demo`)

Ветка `ver-2`. Миграции нет. Решения владельца 2026-10-23: демо-цены — по МИНИМУМУ рыночной вилки, если вилка есть
(`build_approved_market_references`), иначе выдуманные круглые; ветка `ver-2`, push без запроса.

## Что делает

`python -m app.cli.demo seed|remove|status (--email E | --telegram-id N)` — для одного аккаунта (веб-аккаунт V2-1 или Telegram).

| Команда | Действие |
| --- | --- |
| `seed` | Создаёт клиента «Demo» (`notes` начинаются с `[DEMO]`), объект «DEMO · Mieszkanie 50 m²» и 5 помещений с размерами (Salon, Sypialnia, Kuchnia, Łazienka, Przedpokój; ≈ 50 м²) с четырьмя стенами в каждом. Прайс: достраивает каталог аккаунта и ставит цену ТОЛЬКО позициям, у которых цены ещё нет («Do ustalenia»). Повторный запуск ничего не дублирует. `--no-prices` — без цен. |
| `remove` | Архивирует и удаляет навсегда демо-объект и демо-клиента (через те же службы, что экран «Архив»; фото и документы демо-объекта, если владелец их добавил, тоже уходят штатным путём или команда отказывает с причиной). Цены, которые ещё равны демо-значению, возвращает в «Do ustalenia»; изменённые владельцем не трогает. `--keep-prices` — цены оставить. |
| `status` | Что из демо есть у аккаунта (объект, клиент, сколько цен равны демо-значению). |

## Правила

* Цены лежат на бэкенде (`app/domain/data/demo_data.py`), не во фронтенде. Источник значения каждой цены: минимум вилки
  из утверждённых данных рынка или таблица выдуманных значений для 21 позиции без рыночных данных.
* Реальные цены владельца не перезаписываются никогда (ставим только при `price IS NULL`).
* Демо-данные узнаются по метке (имя объекта с префиксом `DEMO · `, `[DEMO]` у клиента): `remove` не трогает ничего другого.
* На проде ничего не создаётся, пока владелец сам не запустит команду.
