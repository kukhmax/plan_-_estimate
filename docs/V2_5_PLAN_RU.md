# V2-5 — план работ на уровне помещения

Ветка `ver-2`. **Миграция 0068** (две новые таблицы + один столбец; обратимая; существующие данные не меняются). Решения владельца 2026-10-24: общий план комнаты + «стена следует плану»; потолок — в том же плане отдельным списком; стены с начатыми работами не трогаются и показываются в списке «пропущены».

## Модель

* `room_work_plans` — один план на помещение (подложка, класс) и `room_planned_works` — его работы: список для **стен** и список для **потолка** (порядок, ссылка на строку прайса; без цен). Коэффициенты и технологические паузы у общего плана не задаются (они остаются у конкретной стены).
* `surface_work_plans.follows_room_plan` (по умолчанию `false`): план поверхности «следует общему плану». Все существующие планы остаются как есть (`false` = «свой план»).

## Правила

* Сохранение общего плана (`PUT /api/projects/{p}/rooms/{r}/work-plan`) записывает план и обновляет поверхности помещения:
  * стена/потолок **без плана** — получает план из общего и начинает ему следовать (`CREATED`);
  * поверхность, которая уже **следует** общему плану — план заменяется (`UPDATED`), ключи работ (`occurrence_key`) сохраняются для тех же строк прайса;
  * поверхность со **своим** планом — не трогается (`SKIPPED_OWN`);
  * поверхность, у которой выполнение начато (IN_PROGRESS / COMPLETED) — не трогается (`SKIPPED_STARTED`); выполненное не стирается никогда.
  Ответ перечисляет исход по каждой поверхности.
* Любое обычное изменение плана конкретной стены (редактор плана, шаблон, добавление рекомендованной работы, «Zastosuj do ścian») делает её «своим планом» (`follows_room_plan = false`).
* «Wróć do planu pokoju» (`POST …/surfaces/{s}/work-plan/follow-room-plan`) применяет общий план к этой поверхности и возвращает её в «следует» (кроме начатых — 409).
* Пустой список для цели не создаёт пустых планов; у следующих он очищает работы.
* Смета и всё остальное читают обычные планы поверхностей: расчёт не меняется.

## Экран

В списке поверхностей помещения кнопка «Plan pomieszczenia»: лист (подложка, класс, два списка работ «Ściany» и «Sufit» с добавлением из прайса, порядком и удалением) → «Zapisz» → отчёт «Zaktualizowano N, pominięto M (свой план / начаты)». На карточке стены метка «Plan pokoju» / «Własny plan» и кнопка «Wróć do planu pokoju».

## Тесты / PASS

Бэкенд: модель и миграция (PG16 up/down/up на базе с данными), создание/замена/пропуски (свой план, начато), ключи работ, потолок отдельно, пустые списки, смена обычного плана → «свой», «вернуть», чужой аккаунт, шифрование, 401, аудит API. Фронтенд: лист плана, отчёт, метки, возврат. Реальное приложение на всех размерах. Выкладка с миграцией: `docs/V2_5_DEPLOY_RU.sh` (бэкап A9 ≤ 24 ч, `ВЫКЛАДКА ДА`).
