# V2-11 — пакеты «Плитка» и «ГКЛ»: расчёт материалов, ведомость, справочник норм

Решения владельца (2026-10-29, после приёмки V2-10): результат — **ведомость материалов и строки в смету** (с ценами из вашего прайса); **справочник норм вы правите сами** (в приложении есть стартовые типовые цифры — ориентир, проверьте по техкартам своих материалов); пакеты — **«Плитка»** (плитка, клей, затирка, гидроизоляция, лента, крестики) и **«ГКЛ»** (листы, профили UD и CD, подвесы, саморезы, шпаклёвка для швов, лента).

## Идея
Расчёт материалов — **чистая функция** от ваших исходных данных и **норм** (правило проекта: детерминированно, без ИИ; цены в формулах не участвуют, только в сметной строке из прайса). Результат нигде не хранится — считается при каждом открытии (хранятся только исходные данные расчёта и нормы).

## 1. Расчёты у помещения («Materiały»)
Расчёт — строка помещения: **название** («Podłoga łazienki», необязательно, шифруется) + **вид** + исходные данные. У помещения может быть несколько расчётов (пол плиткой, стены плиткой, потолок ГКЛ). Площадь вы вводите сами; в форме рядом предлагаются площади из расчётов помещения (пол, потолок, стены нетто) — касанием подставляются.
* **Плитка:** площадь, размер плитки (см × см), толщина (мм, по умолчанию 8), шов (мм, по умолчанию 3), раскладка «прямая / по диагонали» (разный запас), гидроизоляция (да / нет; площадь гидроизоляции, по умолчанию = площадь плитки; длина ленты — мп).
* **ГКЛ:** вид «стена / потолок», площадь, слоёв 1 или 2, для стены — высота (м), для потолка — периметр (м).

## 2. Формулы (все числа — из справочника норм)
* **Плитка:** площадь с запасом = A × (1 + запас) (запас: 10 % прямая, 15 % диагональ), штук = округление вверх (площадь с запасом ÷ площадь плитки). **Клей** = A × расход по размеру плитки (длинная сторона ≤ 30 см: 3,5; ≤ 60 см: 5; больше: 7 кг/м²), мешков по 25 кг. **Затирка** = A × (a + b) ÷ (a × b) × шов × толщина × плотность 1,6 × (1 + запас 15 %), a и b в мм; мешков по 5 кг. **Гидроизоляция** = площадь × 1,5 кг/м² × 2 слоя, вёдер по 15 кг; **лента** — рулонов по 10 мп. **Крестики** = штук плитки × 1, упаковок по 200.
* **ГКЛ:** листов = округление вверх (A × слоёв × (1 + запас 10 %) ÷ 3,0 м²). **Стена:** UD = 2 × A ÷ H; CD = A ÷ шаг (0,6 м) + H. **Потолок:** UD = периметр; CD = A × 3,0 мп/м²; подвесов 1,5 шт/м². Профилей штук = округление вверх (мп × (1 + запас) ÷ 3,0 м). **Саморезы** = A × слоёв × 25 шт, коробок по 1000. **Шпаклёвка для швов** = A × 0,5 кг, мешков по 25 кг. **Лента для швов** = A × 1,5 мп, рулонов по 90 мп.
* Округление — вверх до целой упаковки; для **всего объекта** упаковки округляются один раз по сумме расчётов, а не по каждому расчёту.

## 3. Справочник норм (миграция 0078)
Таблица `material_norms` у владельца (создаётся при первом открытии, стартовыми цифрами): **числа** (запасы, расходы, размеры упаковок, шаги) и **материалы** (название, упаковка → какая позиция вашего прайса даёт цену). Любое число можно изменить и вернуть к стартовому («по умолчанию»). Позицию прайса можно привязать к материалу, если её единица подходит (м² для плитки, шт для упаковок и профилей); без привязки строка сметы получится «Do ustalenia».

## 4. Ведомость и смета
* Ведомость помещения — внутри расчёта; ведомость **объекта** — плитка «Materiały» на экране объекта: итоги по материалам (количество, упаковки, цена и сумма, если привязан прайс), расчёты по помещениям, справочник норм.
* **В смету:** кнопка «Dodaj materiały do kosztorysu» на черновике: по строке на материал (сумма по объекту), снимок: название, единица, количество упаковок, цена прайса на этот момент; повторное нажатие уже добавленное не дублирует (смета — снимок, как у точек и трасс). Строки ручного происхождения: перегенерация плана работ их не трогает.

## 5. Данные и API (владелец-скоуп, Pydantic v2)
* Миграция **0078** (обратимая): `material_norms`, `material_calcs` (обе с каскадом по объекту / помещению / владельцу); откат **отказывается**, пока есть расчёты или изменённые вами нормы (ввод владельца).
* `GET /api/material-norms`, `PATCH /api/material-norms/{id}`; `GET/POST /api/projects/{id}/rooms/{room}/material-calcs`, `PATCH/DELETE …/{calc}`; `GET /api/projects/{id}/materials`; `POST /api/projects/{id}/estimates/{estimate}/add-materials`.

## Критерии PASS
1. Формулы — чистые тесты с вручную посчитанными числами (граничные размеры плитки, 1 и 2 слоя, стена и потолок, округление упаковок, сумма по объекту).
2. Нормы: старт идемпотентен, правка и возврат, проверки диапазона и единицы привязанной позиции; чужой владелец — 404; расчёт без нормы не падает.
3. Смета: строки, цена из привязанной позиции, «Do ustalenia» без привязки, без дублей, только черновик.
4. Миграция 0078 вверх / вниз / вверх на PG16; откат отказывает при данных.
5. Экран: 4 языка, 320 / 390 / 419, светлая / тёмная, нет горизонтальной прокрутки, цели ≥ 44 px, микрофон у чисел; регрессия (4 шарда, vitest, tsc, build); скрипт выкладки с миграцией и пробный прогон; README пошагово.
